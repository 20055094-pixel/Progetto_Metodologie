# 🍳 CookBook - Piattaforma Ricette

Una piattaforma web completa per la gestione e condivisione di ricette culinarie.

## Avvio Rapido

1. Installa le dipendenze:
   
   npm install
   

2. Avvia il server:
   
   npm run dev
   npm start
   

3. Apri il browser:

   http://localhost:3000
